💬 Doc Request Intake — Live Chat

Real conversation, backed by Azure OpenAI. Describe what you need — the agent will ask a couple of clarifying questions, then propose a card for you to confirm. This prototype only previews the card; it does not create the ADO item yet.

⚠️ This page calls /api/chat, a small Azure Functions API that holds the Azure OpenAI key server-side. It only works once deployed to Azure Static Web Apps with that API configured — it will show a connection error on GitHub Pages or when opened as a local file.
